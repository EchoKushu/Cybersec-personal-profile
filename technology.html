Penetration testing

Choose the right testing perspective

Penetration testing is an authorised, scoped security exercise designed to identify exploitable weaknesses. The type of test should match the system, the risk and the evidence needed.

Black-box

External, limited-knowledge testing

The tester has little or no prior knowledge of the environment, reflecting an outside attacker's starting position.

Grey-box

Partial-knowledge testing

Selected access or system information provides useful context while preserving realistic discovery and validation.

White-box

Full-knowledge testing

Architecture, source information or credentials are available for detailed coverage and efficient validation of control weaknesses.

External

Internet-facing systems

Testing of public websites, exposed services and edge infrastructure to assess external attack paths.

Internal

Internal network testing

Assessment of risks from an approved internal position, including network segmentation, account access and lateral movement controls.

Web application

Application & API testing

Review of web applications and APIs for authentication, authorisation, input handling and business-logic weaknesses.

Mobile

Mobile application testing

Review of mobile application behaviour, stored information, authentication and supporting services.

Wireless

Wi-Fi & wireless testing

Assessment of wireless configuration, authentication, segmentation and unauthorised access risks.

Cloud

Cloud security testing

Assessment of approved cloud resources, identity controls, permissions and exposed configuration.

Other specialist testing

Red-team exercises, advanced social engineering, physical security testing and some managed security activities may require a separately qualified specialist team. These may be coordinated through appropriate partners rather than advertised as directly delivered unless a verified arrangement is confirmed.

Every engagement requires written authorisation, defined scope, agreed test limits and a clear reporting approach.

Specialist delivery

Clear boundaries and the right expertise

Echo Kushu provides practical review, planning and implementation support. Specialist work requiring independently qualified expertise may be delivered through appropriately competent partners, with the scope clearly defined before engagement.

This approach helps organisations receive proportionate support without overstating capability or specialist credentials.
